AlloCiné Web Scraper 

Script Python pour l'extraction automatique et la structuration des données des films à l'affiche sur **AlloCiné**.

Fonctionnalités
- Extraction dynamique des titres, réalisateurs, dates de sortie, synopsis et visuels (affiches).
- Gestion des requêtes HTTP avec en-tête `User-Agent` pour le contournement des blocages.
- Structuration automatique sous forme de **DataFrame Pandas**.
- Rendu visuel interactif en cartes HTML au sein d'un Jupyter Notebook.
